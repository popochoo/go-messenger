# GoMessenger — Real-Time Web Messenger

Веб-мессенджер с поддержкой личных (1-1) и групповых чатов, мгновенной доставкой сообщений через WebSockets и Redis Pub/Sub, курсорной пагинацией истории и базовой модерацией.

## Архитектура и технологический стек

- **Backend:** Go (`Gin`, `gorilla/websocket`, `pgx/v5`, `go-redis/v9`, `cleanenv`, `slog`)
- **База данных:** PostgreSQL 18 (индексы `B-Tree` для курсорной пагинации и `GIN pg_trgm` для поиска по подстроке)
- **Брокер и Кэш:** Redis 8.6 (горизонтальное масштабирование WS-событий через `Pub/Sub` + антиспам `Rate Limiting`)
- **Инфраструктура:** Docker, Docker Compose, `golang-migrate`, изоляция портов БД через `socat`
- **Frontend:** Встроенный одностраничный Web UI (`web/index.html`)

### Ключевые решения System Design

1. **Масштабирование WebSockets:** При отправке сообщения сервер сохраняет его в PostgreSQL, мгновенно возвращает отправителю `message.ack` (`delivered`) и публикует событие в канал Redis Pub/Sub. Все инстансы приложения подписаны на канал и маршрутизируют события своим активным WebSocket-клиентам.
2. **Защита от дублей 1-1 чатов:** Используется атомарная вставка `INSERT ... ON CONFLICT (direct_key) DO NOTHING` с детерминированным ключом `minUserID_maxUserID`.
3. **Курсорная пагинация:** Подгрузка истории вверх (`GET /messages?cursor=<id>&limit=30`) работает по составному индексу `(chat_id, id DESC)` за $O(\log N)$ без деградации `OFFSET`.
4. **Антиспам (Rate Limiting):** Фиксированное окно в Redis ограничивает частоту отправки сообщений (не более 5 сообщений за 10 секунд на пользователя).

## Быстрый старт (Docker)

1. Скопируйте файл с примером переменных окружения:
   ```bash
   cp .env.example .env
   ```
2. Запустите всю инфраструктуру, миграции и приложение одной командой:
   ```bash
   make app-up
   ```
3. Откройте веб-интерфейс в браузере: **`http://localhost:8080/`**

## Полезные команды Makefile

- `make app-up` — собрать и запустить весь стек в Docker + применить миграции
- `make app-down` — остановить все контейнеры
- `make env-up` — запустить только инфраструктуру (Postgres + Redis) для локальной разработки
- `make gomessenger-run` — запустить Go-сервер локально без Docker
- `make migrate-up` / `make migrate-down` — применить или откатить миграции БД
